# Visual Direction

TapTune is presented as a workshop field guide: warm paper, ink-black type, cobalt system marks, orange physical signals, and green playback. The page deliberately avoids a generic dark-tech landing page and uses the physical tap-to-play loop as its visual grammar.

- **Typography:** Space Grotesk for expressive headings, DM Sans for readable copy, DM Mono only for code and system labels.
- **Color:** paper `#f4f1e8`, ink `#182027`, cobalt `#1945e8`, signal orange `#f06328`, playback green `#20734f`.
- **Composition:** editorial reading flow with a tactile first viewport, a three-step loop, a signal-path blueprint, and a numbered installation field guide.
- **Interaction:** links and buttons use explicit hover and focus states; motion is limited and reduced under `prefers-reduced-motion`.
