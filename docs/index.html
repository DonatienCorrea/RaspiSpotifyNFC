Raspberry Pi + NFC + Spotify

RaspiSpotifyNFC

Tap a tag to play a playlist, resume a track, or trigger a simple control action.

GitHub repo Setup guide

What this project does

  • Reads NFC tags with an RC522 reader connected to a Raspberry Pi.
  • Maps each tag to a Spotify URI or an action such as play/pause or next track.
  • Lets you assign tag values from a small local web interface.
  • Stores the tag mapping and resume state in SQLite.
  • Works in a fake mode for testing without hardware or a live Spotify token.

Hardware

  • Raspberry Pi 5
  • RC522 NFC reader
  • SPI wiring to the Pi
  • Powered speaker via 3.5mm audio out
  • Spotify Connect-ready playback on the Pi

Tag behavior

  • Content tag: spotify:playlist:...
  • Content tag: spotify:album:...
  • Content tag: spotify:track:...
  • Control tag: action:play_pause
  • Control tag: action:next

Installation on a new Raspberry Pi

  1. 1. Install Raspberry Pi OS Lite

    Use Raspberry Pi Imager to install Raspberry Pi OS Lite on the SD card.

    Enable SSH, Wi‑Fi, and set a hostname if needed.

  2. 2. Update the system

    sudo apt update && sudo apt upgrade -y

  3. 3. Install Python tooling

    sudo apt install -y python3 python3-pip python3-venv git

  4. 4. Clone the project

    git clone https://github.com/DonatienCorrea/RaspiSpotifyNFC.git
cd RaspiSpotifyNFC

  5. 5. Create a virtual environment

    python3 -m venv .venv
source .venv/bin/activate

  6. 6. Install dependencies

    pip install -r requirements.txt
pip install -r requirements-pi.txt

  7. 7. Copy the env file

    cp .env.example .env

  8. 8. Add your Spotify configuration

    Edit .env and set:

    SPOTIFY_CLIENT_ID=your-client-id
SPOTIFY_CLIENT_SECRET=your-client-secret
SPOTIFY_REDIRECT_URI=http://localhost:8888/callback
SPOTIFY_REFRESH_TOKEN=your-refresh-token

    Use a shared household Premium Spotify account for the Pi's playback account.

  9. 9. Initialize the database

    python -m app.main

    The app will create the SQLite database automatically on first run.

  10. 10. Start the app

    python -m app.main

    Open the app in the browser on the Pi or LAN IP:

    http://raspberrypi.local:5000

Write and assign tags

Open the web UI, paste the tag UID, and assign a Spotify URI or action value.

Examples:

spotify:playlist:37i9dQZF1DXcBWIGoYBM5M
spotify:album:4aawyAB9vmqN3uQ7FjRGTy
action:play_pause
action:next

Testing without hardware

python -m app.simulate --uid 01AABBCC --payload "spotify:playlist:37i9dQZF1DXcBWIGoYBM5M"
python -m app.simulate --uid 02AABBCC --payload "action:play_pause"

This exercises the same dispatch path as a physical NFC tag.

Run tests

python3 -m unittest discover -s tests -v
